# UWB-MIMO-Antenna-Using-Staircase-and-Combline-structure
Designed a compact UWB-MIMO antenna using ANSYS HFSS with a staircase-shaped patch and comb-line ground structure to improve bandwidth and reduce mutual coupling. Evaluated S-parameters, isolation, radiation patterns, gain, efficiency, and ECC to assess its suitability for next-generation wireless communication systems.
